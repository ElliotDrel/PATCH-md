# Changelog

All notable changes to PatchMD are documented here. Releases follow semantic
versioning; specification compatibility is called out explicitly.

## 0.2.0 - 2026-07-02

- Add a guarded npm installer with explicit forced replacement.
- Add installer integration tests and parsed YAML validation.
- Add a provenance-enabled npm release workflow.
- Define specification version discovery, forward compatibility, normative
  terminology, conformance fixtures, and 1.0 graduation criteria.
- Pin the agent-first installation URL to a release.

Compatibility: Draft 0.1 records remain structurally compatible after adding
`PatchMD version: 0.2` to the Upstream section.

## 0.1.0 - 2026-06-20

- Publish the initial PatchMD draft, template, examples, and three lifecycle
  skills.
