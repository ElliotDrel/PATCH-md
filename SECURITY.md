# Security

Report vulnerabilities privately through GitHub's security-advisory interface
for this repository. Do not open a public issue for a vulnerability that could
cause code execution, data loss, or unsafe replacement of repository files.

PatchMD skills and installers can influence source-control operations. Pin
installations to a released version, review proposed changes, preserve rollback
references, and never provide repository or registry credentials to a skill.

The latest released minor version receives security fixes while PatchMD remains
in draft. Supported Node.js versions are declared in `package.json`.
